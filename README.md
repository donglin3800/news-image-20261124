A Python 3.13 program that draws a one-page newspaper front page summing up Tuesday 24 November 2026 in five verified stories — three tankers hit mines in Hormuz, Israel kills Hamas' security chief in Gaza, a Russian strike on Zaporizhzhia, Sanofi's $41bn Insmed deal, and a 5.6 quake in Nepal — and writes it as a 1024×1024 PNG. Pure standard library: a small software rasterizer and a hand-built stroke font, no network, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
